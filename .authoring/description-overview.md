# Cadastro de vendedores e relatório semanal de uma loja

A administração de uma loja precisa manter o cadastro dos seus vendedores, e a equipe de vendas precisa conferir os comprovantes da semana, inclusive os de vendas sem vendedor identificado. A aplicação web em Python (Flask) e as telas já estão prontas: você completa, em SQL, as funções de repositório que faltam, sobre um banco PostgreSQL no Supabase.

Você vai praticar a inclusão, a consulta, a alteração e a exclusão de registros e a recuperação de dados relacionados de várias tabelas num período.

Para começar, abra o caso, leia o pedido da gerência e prepare o projeto conforme o README. Você precisa de Python 3.9 ou mais recente e de um projeto no Supabase.
